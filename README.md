# *Cracking the Coding Interview*
By Gayle Laakmann McDowell

---

## Outline of concepts
In this repository, I aim to implement the concepts and algorithms outlined in *Cracking the Coding Interview*.
Below is a list of the algorithms contained in this repo:
1. **Arrays and Strings**
   1. Hash Tables
   2. ArrayList & Resizable Arrays
   3. StringBuilder
2. **Linked Lists**
3. **Stacks and Queues**
   1. Stacks
   2. Queues
4. **Trees and Graphs**
   1. Types of trees
   2. Binary Tree Traversal
   3. Binary Heaps (Min-heaps and Max-heaps)
   4. Tries (Prefix Trees)
   5. Graphs and Graph Searching
